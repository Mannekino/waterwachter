# Waterwachter

Waterwachter is een command-line applicatie die actuele en historische watermetingen ophaalt via de Rijkswaterstaat WaterWebservices API.

## Functionaliteiten

- Meetlocaties opzoeken
- Actuele waterstanden bekijken
- Historische metingen raadplegen
- Favoriete locaties beheren

## Technieken

- Python
- Requests
- Rich
- JSON-opslag
- Git
